# WMC IPTV

WMC IPTV brings modern IPTV and live-TV sources into Windows Media Center using virtual HDHomeRun tuners.

Created and developed by Boxcar32.

## Tested Environment

- Windows 11 (OS Build 26200)
- Garyan2's Windows Media Center installation
- HDHRProxyIPTV virtual tuners
- EPG123 guide integration

## Documentation

See **WMC IPTV User Manual.pdf** for installation requirements and setup instructions.

## Important

Windows Media Center and the required HDHomeRun/BDA environment must be configured before WMC IPTV channel installation.

Windows 7 support is currently under development/testing.
